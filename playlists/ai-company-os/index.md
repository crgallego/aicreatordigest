# Software Factories Meet Company OS: Where Agentic Workflows and Org Design Converge

Two creators map how AI work gets systematized beyond individual operators. Dan Eisler reframes agentic engineering as software-factory workflows that combine engineers, agents, and code; Jiaona Zhang (on Aakash Gupta's show) shows how Laurel encodes the 1% AI-pilled operators' skills into a GitHub-based company OS delivered just-in-time in Slack. They align on treating AI leverage as designed infrastructure—not vibe coding or personal prompts—but diverge on scope, who ships, and how the system reaches the rest of the org.

*Synthesized from 2 videos by 2 creators.*

---

## Where They Agree

- AI leverage is a designed system, not ad-hoc tool use. Dan calls out loop engineering as a shallow SDLC rebrand and pushes AI developer workflows and software factories; Jiaona builds a company OS so workflows reach the whole org, not just the 1%.
- Code and structured files are the real substrate. Dan calls code the unsung hero among the three actors of value creation (engineers, agents, code); Jiaona runs the company OS on GitHub—function folders, skill files, ontologies.
- Separate skills from the work product. Dan's practical rule is separate code from skills; Jiaona encodes operator skills into shared GitHub skill files surfaced just-in-time.
- Scale the system, not hero effort. Dan wants to scale compute, not engineer effort; Jiaona's whole point is closing the 1% vs 99% AI gap so the other 90–99% know what to use when.
- Humans stay at the control points. Dan keeps engineers at start and end of factory workflows; Jiaona uses captains, two-track product review, and AI ops as the new biz ops.
- This is meta-work, not vibe coding. Dan labels it meta-engineering over vibe coding; Jiaona stresses fundamentals hold while tools changed—and staffs lean senior IC product orgs to run it.

## Open Disagreements

- Scope: Dan centers AI developer workflows and sandboxed software factories for engineering paths (including production hotfixes). Jiaona centers a company-wide OS that reaches PMs, CS, and non-engineering operators via Slack delivery.
- Who ships product work: Dan's model keeps engineers as the human actors bracketing agent runs. Jiaona has PMs shipping front-end and back-end with Devin, and replaces rigid roles with a captains model.
- Primary distribution surface: Dan scales through work trees, full sandboxes, and an agentic layer over the app layer. Jiaona's delivery loop is GitHub skill files surfaced just-in-time in Slack so the 99% actually use them.
