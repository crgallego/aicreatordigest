## Key Takeaway

## In Context

ambITious | AI walks through LeadStack, a self-hosted CRM positioned as a direct alternative to GoHighLevel, Pipedrive, and HubSpot for agencies and small businesses that only use a fraction of what they pay for. The video is a live product demo and setup walkthrough: sign up, pull the repo, and let Claude Code guide configuration via a Claude.md file. It covers the multi-tenant agency model, pipelines, contacts, form-triggered email/SMS automations, and a Get Page–powered website builder, then closes with one-time pricing, free-tier hosting/email/SMS economics, and a planned 40% affiliate program.

## Key Points

1. **CRM subscriptions are optional now** — Pipedrive runs $49 per user per month ($150 for a team of three), GoHighLevel’s middle tier is $297/month, and HubSpot Professional is $800/month plus onboarding. Most small businesses pay thousands a year and use maybe 20% of the product—contacts, pipeline, sub accounts, automation, and a form.
2. **LeadStack is a business in a repo** — Out of the box you get unlimited sub accounts, full activity timeline, contacts with search and CSV import, calendar and tasks, form builder, email and SMS automations, plus website and funnel builders. Setup is framed as sign up, download, fire it up—with Claude Code guiding the full process.
3. **Under 60 minutes to a running CRM** — The creator claims everything shown can be set up and running in less than 60 minutes, customized to your brand, theme, and style rather than a generic SaaS skin.
4. **Multi-tenant agency and sub accounts** — LeadStack supports an agency model with unlimited sub accounts and members. Agency owners can invite clients as collaborators so they only see their own workspace—demoed with a Peak Clubs / Peak Fitness deal won at $50,000.
5. **Pipeline, contacts, and map views** — A sample sub account shows 53 open deals, ~$322,000 pipeline value, $300,000 won that month, and 300 contacts, with filters for stage and priority plus a geographic map of deals (UK/London-centered in the demo).
6. **Form-to-automation lead capture flow** — Forms default to creating a new pipeline lead, auto-tagging the source, and adding the contact. Templates cover welcome SMS, welcome email (with calendar link), and notify-owner; enable the chain and submissions fire the sequence.
7. **Website builder via Get Page API** — Niche templates (e.g. gym and fitness) call Get Page during setup to generate and publish a site on a free GitLab subdomain. Custom form HTML is copied from LeadStack and handed to Claude Code (with GetPage MCP) so the form matches the site design instead of an iframe embed.
8. **One-time buy, near-free run costs** — LeadStack is a one-time payment (price withheld on camera due to a first-50 deal that then rises significantly). Hosting is self-hosted and near-free until significant monthly users; email has a large free tier; SMS is cents per message. Git Page agency tier is included for the first batch of users. A 40% affiliate program is planned to align with GoHighLevel.

## Tactics

### Claude.md guided setup _(workflow)_

A Claude.md file ships in the codebase. Ask Claude Code to “Guide me through the setup for the Lead Stack” and it walks the full install. Claude Code is recommended but not required for build and setup.

### Agency client onboarding loop _(workflow)_

Create a sub account, enter client details, invite them as collaborator/admin so they only see their workspace, add the signed deal to the pipeline, attach form-triggered SMS/email automations, then generate their niche website and inject the form HTML via Claude Code.

### Custom form HTML into generated site _(workflow)_

Copy the form’s HTML snippet from LeadStack, have Claude retrieve the Get Page site via MCP, and ask it to insert the snippet so the contact form matches the site instead of breaking look-and-feel with an embed.

### Own the 20% you actually use _(pricing)_

Strip the stack to contacts, pipeline, sub accounts, automation, and a website form—no monthly CRM subscription, no transaction cuts, no plugins. Pay once for the repo; run on free tiers until volume forces paid email/SMS/hosting.
