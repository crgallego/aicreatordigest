### [FORGET Loop Engineering. Agentic Engineering is about THIS](/video/ai-company-os/forget-loop-engineering-agentic-engineering-is-about-this)

> Stop calling it loop engineering — the real leverage is designing AI developer workflows that combine engineers, agents, and code into software factories.

Indie Dev Dan argues loop engineering is a shallow rebrand of the SDLC and reframes the real work as AI developer workflows that combine engineers, agents, and code. He scales from simple lint loops to sandboxed software factories and specialized paths like production hotfixes, with practical rules: keep it simple, separate code from skills, and design workflows by running them yourself first.
